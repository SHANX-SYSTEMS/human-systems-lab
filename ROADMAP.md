# Roadmap

## v0.1 — Open-source core

- experiment module contract
- deterministic seeded trial generation
- local session queue
- sync-receipt interface
- protocol validation examples
- synthetic end-to-end demo
- research-integrity and security documentation
- reproducibility and tamper checks

## v0.2 — General experiment engine

- multiple experiment modules
- manifest registry
- module versioning
- local-only mode
- backend-adapter interface
- analysis-run interface
- session recovery tests

## v0.3 — Research collaboration

- reusable preregistration template
- protocol-diff viewer
- community experiment workflow
- synthetic benchmark suite
- accessibility and mobile-input validation

## Explicitly out of scope

- diagnosis
- medical claims
- covert behavioral profiling
- manipulative attention capture
- publishing private participant data
- treating weak evidence as scientific truth
