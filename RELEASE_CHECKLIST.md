# Public Release Checklist

Before publishing a release:

- [ ] protocol and tests are reproducible
- [ ] CI is green
- [ ] no private participant rows are present
- [ ] no production tokens, keys, passwords, or secrets are present
- [ ] no private backend project IDs or internal workspace references are present
- [ ] sample data is synthetic or explicitly approved for publication
- [ ] experiment claims match the evidence level
- [ ] failed hypotheses are preserved as failures
- [ ] license and NOTICE are present
- [ ] security and privacy docs are current
- [ ] public README accurately describes what is and is not included
