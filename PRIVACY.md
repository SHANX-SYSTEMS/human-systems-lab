# Privacy

Human Systems Lab is designed to minimize data collection.

## Default principles

- collect only data necessary for the declared experiment
- prefer pseudonymous participant identifiers
- avoid direct identifiers unless the study genuinely requires them
- do not silently collect camera, microphone, precise location, contacts, passwords, financial credentials, or unrelated device data
- keep raw evidence separate from derived analysis
- define retention and deletion rules before recruiting external participants
- use explicit consent appropriate to the study context
- do not publish participant-level data by default

## Public repository

This public repository contains code, protocols, schemas, synthetic examples, and documentation. It must not be used as a storage location for private participant records.

## External studies

Researchers are responsible for the legal, ethical, institutional, consent, privacy, and security requirements that apply to their participants and jurisdiction.
