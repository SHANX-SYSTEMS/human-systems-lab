# ATTENTION-001

ATTENTION-001 is included as a public protocol lineage used to develop and pressure-test the Human Systems Lab infrastructure.

It is **not** presented as proof of a universal mechanism of human attention.

## Research question family

How do target similarity, salience, experience, and location history influence visual-search behavior?

## Methodological lesson

Successive internal versions exposed plausible-looking effects that also had alternative explanations. The protocol evolved by attacking those confounds rather than preserving a preferred theory.

The public lesson is the process:

**question → preregister → run → attack the result → preserve failure → repair only if the question remains worth answering**

## v0.5

The public v0.5 example uses:
- 6 practice trials
- matched primary baseline conditions
- unequal distractor-location frequency during training
- equalized transfer
- filler trials that keep candidate locations behaviorally relevant as possible target locations
- a fixed search response before target verification
- an awareness check
- deterministic seeded assignment

Private participant data and private analysis records are intentionally excluded.
