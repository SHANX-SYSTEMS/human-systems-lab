# Contributing

Thank you for helping improve Human Systems Lab.

## Useful contributions

- experiment-engine improvements
- protocol validators
- reproducibility tests
- accessibility improvements
- privacy/security hardening
- synthetic datasets
- documentation
- backend adapters
- well-scoped experiment modules

## Experiment proposals

Please include:

1. research question
2. what existing evidence already establishes
3. why a new test is needed
4. preregistered primary outcome, or explicit exploratory status
5. alternative explanations
6. stopping rule
7. privacy/ethics considerations
8. deterministic or auditable trial-generation logic
9. validation tests

## Pull requests

Keep changes narrow and auditable. Avoid mixing protocol changes and result interpretation in the same commit when possible.

## Data

Do not submit real participant data unless a separate release process has explicitly approved public publication.
